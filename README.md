Ink-Tech Studio

Ink-Tech Studio is a sleek and intuitive web application built to help users create, visualize, and share digital projects with ease. Whether you’re designing mockups or experimenting with layouts, Ink-Tech Studio provides a responsive and collaborative environment for creative exploration.

🔗 Tip: For the best experience, open the app directly in your browser (Chrome, Safari, or any modern browser). You can copy and paste the link below:

https://ink-tech-studio.vercel.app

⸻

🚀 Features
	•	Intuitive Design Interface: User-friendly tools to create and customize your designs.
	•	Real-Time Collaboration: Work simultaneously with team members and see changes live.
	•	Responsive Layouts: Designs adapt seamlessly across devices.
	•	Export Options: Easily export your projects in various formats.
	•	Version Control: Keep track of changes and revert to previous versions when needed.

⸻

🛠️ Tech Stack
	•	Frontend: React, Tailwind CSS
	•	Backend: Node.js, Express
	•	Database: MongoDB
	•	Deployment: Vercel

⸻

📦 Installation
	1.	Clone the repository:

git clone https://github.com/yourusername/ink-tech-studio.git
cd ink-tech-studio


	2.	Install dependencies:

npm install


	3.	Set up environment variables:
Create a .env file in the root directory and add the following:

MONGODB_URI=your_mongodb_connection_string


	4.	Run the application:

npm start

The application will be available at http://localhost:3000.
